# 1.1.0 — Provider Integration Foundation

This release introduces explicit runtime modes and read-only provider adapters.

## Highlights

- AWS Cost Explorer import using the standard SDK credential chain or STS AssumeRole
- Optional AWS Budgets and CloudWatch Billing enrichment
- Kubernetes Deployment and StatefulSet inventory using in-cluster or kubeconfig authentication
- Structural Terraform parsing and constrained fixture paths
- Request IDs, provider sync counters, and route-level request metrics
- Mocked provider failure tests and SQLite-backed API integration tests

## Upgrade Notes

- `OPERATING_MODE` defaults to `demo`. Set it to `connected` before provider sync endpoints will execute.
- Connected and offline modes initialize an empty schema and do not seed simulated records.
- CORS now defaults to `http://localhost:3000`; set `CORS_ORIGINS` to a comma-separated allowlist when the frontend origin differs.
- New Python dependencies are `boto3`, `kubernetes`, and `python-hcl2`.
- Generated recommendations no longer display unsupported monetary savings estimates.

## Limitations

Provider sync endpoints are unauthenticated and synchronous. Kubernetes resource utilization is not collected. This release is a reference implementation and should not be exposed publicly without the controls described in the README and security policy.
